Our honest note on method

Two platforms allow fully signed-out use and were run that way. The other three force a login, so they were run in their temporary or incognito modes with memory and personalisation off. Every question ran in its own fresh conversation, so no answer could contaminate the next. We measure the consumer products through a browser — never the developer APIs — because the API answer is not the answer your buyer sees.
